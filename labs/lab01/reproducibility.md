# Инструкция: диагностика системы Windows 11

Пошаговое руководство для повторения диагностики компьютера под управлением Windows 11 Pro.

---

## Шаг 1. Общие сведения об ОС

- **Инструмент:** `Win + R` → ввести `winver` → Enter
- **Найти:** редакция (Pro), версия (24H2), сборка (26100.8875)
- **Проверка:** версия и сборка отображаются в окне «О программе Windows»

---

## Шаг 2. Архитектура и процессор

- **Инструмент:** `Win + R` → `msinfo32` → Enter
- **Перейти:** раздел «Сводные сведения» (открывается по умолчанию)
- **Найти:** «Тип системы» (x64), «Процессор» (модель, частота), «Версия BIOS»
- **Проверка:** тип системы должен содержать `x64`; в строке процессора — модель и частота

---

## Шаг 3. Оперативная память

- **Инструмент:** `msinfo32` (тот же экран)
- **Найти:** «Полный объем физической памяти» и «Доступная физическая память»
- **Проверка:** значения в МБ; для пересчёта в ГБ разделить на 1024

---

## Шаг 4. Накопители

- **Инструмент:** Проводник → «Этот компьютер»
- **Найти:** для каждого диска — подпись «X ГБ свободно из Y ГБ»
- **Проверка:** суммарный объём и свободное место видны под каждым диском

---

## Шаг 5. Видеокарта и её загрузка

- **Инструмент:** `Ctrl + Shift + Esc` → вкладка «Производительность»
- **Перейти:** раздел «ГП 0» (или название видеокарты слева)
- **Найти:** модель (NVIDIA GeForce GTX 1650), процент использования
- **Проверка:** загрузка обновляется в реальном времени

---

## Шаг 6. Активные процессы

- **Инструмент:** `Ctrl + Shift + Esc` → вкладка «Процессы»
- **Найти:** Discord, Telegram Desktop, Visual Studio Code
- **Зафиксировать:** для каждого — ЦП (%) и ОЗУ (МБ)
- **Проверка:** значения в колонках «ЦП» и «Память»; отсортировать по имени для удобства

---

## Шаг 7. Системные компоненты (BIOS и виртуализация)

- **Инструмент:** `msinfo32`
- **Найти:** «Версия BIOS» (производитель, версия, дата)
- **Дополнительно:** `Ctrl + Shift + Esc` → «Производительность» → «ЦП»
- **Проверка:** в правой нижней части — статус «Виртуализация: Включена»

---

## Шаг 8. Доступная среда работы

- **Командные оболочки:** проверить наличие:
  - `cmd` — `Win + R` → `cmd`
  - `PowerShell` — `Win + R` → `powershell`
  - `Windows Terminal` — поиск в меню «Пуск»
- **VS Code:** проверить ярлык на рабочем столе или в меню «Пуск»
- **Python:** открыть Terminal и выполнить: python --version
- **Проверка:** команда выводит версию (например, `Python 3.14.6`)
