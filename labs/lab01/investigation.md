Список использованных встроенных средств Windows
Окно winver (проверка версии ОС).
Приложение «Параметры» (сведения об устройстве и системе).
Диспетчер задач (характеристики CPU, RAM, загрузка ресурсов).
Утилита «Сведения о системе» (msinfo32).

| Параметр | Способ 1: «Параметры» / `winver` | Способ 2: Диспетчер задач / `msinfo32` |
| --- | --- | --- |
| **Версия Windows** | «Параметры» → «Система» → «О системе» или `winver`: редакция, версия (24H2), сборка (26100.8875) | `msinfo32`: строки «Имя ОС» и «Версия». В диспетчере задач детализации нет |
| **Процессор (CPU)** | «Параметры» → «Система» → «О системе»: модель (Intel Core i5‑10400F), базовая частота | Диспетчер задач («Производительность» → «ЦП»): модель, ядра/потоки, загрузка. `msinfo32`: полные сведения о процессоре |
| **Оперативная память (RAM)** | «Параметры» → «Система» → «О системе»: общий объём (16 ГБ) | Диспетчер задач («Производительность» → «Память»): объём, скорость, тип, занятые слоты. `msinfo32`: «Полный объём физической памяти» |

- Пользовательское пространство — это где работают твои программы: браузер, VS Code, игры, скрипты на Python. Всё, что ты сам запускаешь.
- ОС управляет CPU/RAM/диском/устройствами, чтобы всё не тормозило и не ломалось: раздаёт ресурсы по очереди, не даёт одной программе забрать всё, следит, чтобы файлы не перезаписывались случайно.
- Видно это везде: когда в диспетчере задач видишь загрузку CPU, когда файл копируется и видишь прогресс, когда две вкладки браузера работают одновременно — это ОС как раз и выступает посредником.
