# Диагностика системы: инструменты и результаты

## Использованные встроенные средства Windows

- **Окно `winver`** — проверка редакции, версии и сборки ОС.  
- **Приложение «Параметры»** — сведения об устройстве и системе (объём RAM, модель CPU и др.).  
- **Диспетчер задач** — характеристики CPU и RAM, загрузка ресурсов, активные процессы.  
- **Утилита «Сведения о системе» (`msinfo32`)** — подробные данные о конфигурации ПК (тип системы, версия BIOS, полные сведения о процессоре и памяти).

## Сравнение способов получения ключевых параметров

| Параметр | Способ 1: «Параметры» / `winver` | Способ 2: Диспетчер задач / `msinfo32` |
| --- | --- | --- |
| **Версия Windows** | «Параметры» → «Система» → «О системе»<br>или `winver`<br>→ редакция, версия (24H2), сборка (26100.8875) | `msinfo32`: строки «Имя ОС» и «Версия»<br>В диспетчере задач детализации нет |
| **Процессор (CPU)** | «Параметры» → «Система» → «О системе»: модель (Intel Core i5‑10400F), базовая частота | Диспетчер задач: «Производительность» → «ЦП» → модель, ядра/потоки, загрузка<br>`msinfo32`: полные сведения о процессоре |
| **Оперативная память (RAM)** | «Параметры» → «Система» → «О системе»: общий объём (16 ГБ) | Диспетчер задач: «Производительность» → «Память» → объём, скорость, тип, занятые слоты<br>`msinfo32`: «Полный объём физической памяти» |

## Кратко о роли ОС: пользовательское пространство и управление ресурсами

**Пользовательское пространство** — это среда, где работают ваши программы: браузер, VS Code, игры, скрипты на Python. Сюда относится всё, что вы запускаете самостоятельно.

**Как ОС управляет ресурсами:**  
- Распределяет CPU, RAM, дисковое пространство и устройства между программами, чтобы система не «зависала».  
- Не позволяет одной программе монополизировать ресурсы и мешать остальным.  
- Контролирует доступ к файлам, предотвращая случайную перезапись данных.  

**Где это видно на практике:**  
- В диспетчере задач — текущая загрузка CPU и потребление памяти.  
- При копировании файлов — прогресс‑бар и распределение пропускной способности.  
- При одновременной работе нескольких вкладок браузера или приложений — ОС обеспечивает их параллельную работу без конфликтов.
