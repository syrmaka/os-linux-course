Папка scripts нужна, чтобы держать в одном месте маленькие программы для проверки компьютера. Например, туда можно положить скрипт, который одним нажатием покажет версию Windows, сколько памяти свободно или какие диски есть. Так не придётся каждый раз вручную открывать окна и копировать данные — всё соберётся автоматически.
