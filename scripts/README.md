# Назначение папки `scripts`

Папка `scripts` служит централизованным хранилищем для небольших автоматизирующих скриптов — это помогает держать инструменты диагностики в порядке и быстро к ним обращаться.

## Что можно разместить в папке

- **Скрипт для быстрой проверки версии ОС** — одним запуском выводит редакцию, версию и сборку Windows.  
- **Утилита сбора данных о памяти** — показывает общий объём RAM и сколько сейчас свободно.  
- **Инструмент инвентаризации накопителей** — выводит список дисков, их тип (SSD/HDD) и объёмы свободного/занятого пространства.

## Зачем это нужно

Вместо того чтобы вручную открывать «Параметры», диспетчер задач и другие окна, достаточно запустить нужный скрипт — он автоматически соберёт и выведет ключевые данные о системе. Это экономит время при регулярных проверках и снижает риск ошибок из‑за ручного копирования значений.
