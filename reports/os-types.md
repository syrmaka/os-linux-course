Характеристика «Назначение»: настольная.
Характеристика «Число задач»: многозадачная.
Характеристика «Работа с пользователями»: многопользовательская (по возможностям ОС).
Характеристика «Интерфейс»: комбинированный.
Характеристика «Сфера применения»: общего назначения.
Характеристика «Поддержка сети»: сетевая работа, есть сетевые возможности.

ОС Windows 11 Pro 24H2: применяется на настольных ПК и ноутбуках для работы, учёбы, игр, разработки; тип по назначению — настольная, общего назначения; многозадачность — многозадачная (вытесняющая); интерфейс — комбинированный (GUI + cmd/PowerShell/Terminal); ключевое отличие — закрытый код, широкая поддержка коммерческого ПО и игр.

ОС Ubuntu (Linux): применяется на настольных ПК, серверах, в облаках, контейнерах; тип по назначению — настольная/серверная, общего назначения; многозадачность — многозадачная (POSIX, вытесняющая); интерфейс — комбинированный (GUI + терминал/Bash); ключевое отличие — открытый исходный код, высокая гибкость и доминирование в серверной среде.

ОС Android: применяется на смартфонах, планшетах, ТВ‑приставках, автосистемах; тип по назначению — мобильная, общего назначения; многозадачность — многозадачная (с ограничениями для энергосбережения); интерфейс — графический (сенсорный); ключевое отличие — заточена под мобильные устройства и батарею, приложения работают в песочницах.

ОС FreeRTOS: применяется на микроконтроллерах, в IoT, промышленной автоматике, медтехнике; тип по назначению — специализированная (ОС реального времени); многозадачность — многозадачная (детерминированная, кооперативная/вытесняющая); интерфейс — API (без GUI); ключевое отличие — гарантированное время отклика, минимальный размер (килобайты), работает на малой памяти.

Windows 11 ставят на обычные компьютеры — для учёбы и игр.
Ubuntu часто берут для серверов и экспериментов — она открытая.
Android заточен под телефоны — тут главное батарея и сенсорный экран.
FreeRTOS вообще без интерфейса — нужен там, где всё должно работать чётко и быстро.
У всех по‑разному устроена многозадачность — под разные задачи.
Поэтому ОС выбирают не просто так, а под конкретную цель.
