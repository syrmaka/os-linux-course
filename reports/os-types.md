# Характеристики Windows 11 Pro 24H2

| Характеристика | Значение |
| --- | --- |
| Назначение | Настольная |
| Число задач | Многозадачная |
| Работа с пользователями | Многопользовательская (по возможностям ОС) |
| Интерфейс | Комбинированный |
| Сфера применения | Общего назначения |
| Поддержка сети | Сетевая работа, есть сетевые возможности |

---

## Сравнение операционных систем

| ОС | Где применяется | Тип по назначению | Многозадачность | Интерфейс | Ключевое отличие |
|---|---|---|---|---|---|
| Windows 11 Pro 24H2 | Настольные ПК и ноутбуки для работы, учёбы, игр, разработки | Настольная, общего назначения | Многозадачная (вытесняющая) | Комбинированный (GUI + cmd/PowerShell/Terminal) | Закрытый код, широкая поддержка коммерческого ПО и игр |
| Ubuntu (Linux) | Настольные ПК, серверы, облака, контейнеры | Настольная/серверная, общего назначения | Многозадачная (POSIX, вытесняющая) | Комбинированный (GUI + терминал/Bash) | Открытый исходный код, высокая гибкость и доминирование в серверной среде |
| Android | Смартфоны, планшеты, ТВ-приставки, автосистемы | Мобильная, общего назначения | Многозадачная (с ограничениями для энергосбережения) | Графический (сенсорный) | Заточена под мобильные устройства и батарею; приложения в песочницах |
| FreeRTOS | Микроконтроллеры, IoT, промышленная автоматика, медтехника | Специализированная (ОС реального времени) | Многозадачная (детерминированная, кооперативная/вытесняющая) | API (без GUI) | Гарантированное время отклика, минимальный размер (килобайты), работает на малой памяти |

## Выводы

- **Windows 11** ставят на обычные компьютеры — для учёбы и игр.  
- **Ubuntu** часто берут для серверов и экспериментов — она открытая.  
- **Android** заточен под телефоны — тут главное батарея и сенсорный экран.  
- **FreeRTOS** вообще без интерфейса — нужен там, где всё должно работать чётко и быстро.  

У всех по‑разному устроена многозадачность — под разные задачи. Поэтому ОС выбирают не просто так, а под конкретную цель.
